# Stackly

Static project with no build step. Keep the HTML, CSS, JavaScript, and image files in the same folder.

- `index.html` - responsive landing page with About Us, menu/order online, contact, and quick-link footer sections
- `styles.css` / `script.js` - landing page and authentication styles and behavior
- `login.html` / `signup.html` - separate, full-screen account pages
- `app.html` / `app.css` / `app.js` - interactive mobile ordering-flow demo
- `stackly-logo.png` / `stackly-logo-transparent.png` - supplied logo and background-blended version

Open `index.html` in a browser. “Order Online” scrolls to the menu on the same page. Food photography and fonts load from external services when online. The authentication forms are front-end previews and need a backend to create or verify accounts.
